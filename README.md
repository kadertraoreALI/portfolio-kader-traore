# Portfolio de Traoré Kader Ali

Portfolio statique multipage publié sur https://kadertraoreali.github.io/portfolio-kader-traore/.

## Pages

- `index.html` : accueil et réalisations sélectionnées.
- `profil.html` : parcours, diplômes et certificat AFD.
- `expertises.html` : compétences et outils.
- `experiences.html` : expériences professionnelles et engagement associatif.
- `projets.html` : neuf réalisations classées par compétences, avec filtres et détails.
- `contact.html` : coordonnées, LinkedIn et CV.

## Organisation des projets

Les réalisations sont organisées en quatre domaines : recherche et économétrie ; statistiques et Data Analytics ; évaluation des politiques publiques ; gestion de projets et enquêtes. Les projets et les sept PDF de la version précédente sont conservés. Les illustrations du Médicobus sont des emplacements temporaires, indiqués comme tels.

## Déploiement

Le site ne nécessite ni compilation ni dépendances JavaScript. GitHub Pages publie la branche `main` depuis `/ (root)`. Les fichiers `site.css` et `site.js` sont partagés entre les six pages ; `.nojekyll` permet de servir directement les fichiers statiques. Le fichier de vérification Google, `robots.txt` et le plan du site restent présents.
